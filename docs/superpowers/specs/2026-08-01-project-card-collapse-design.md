# 프로젝트 카드 접기 기능 설계

## 목표

프로젝트 목록의 각 카드를 독립적으로 접고 펼칠 수 있게 한다. 사용자가
접은 상태는 같은 브라우저의 다음 방문과 새로고침에서도 유지한다.

## 사용자 경험

- 각 프로젝트 이름 왼쪽에 접기/펼치기 화살표 버튼을 표시한다.
- 프로젝트 이름은 기존처럼 상세 페이지 링크로 유지한다. 이름 클릭은 접기
  상태를 바꾸지 않는다.
- 펼친 카드에는 기존의 모든 저장소, 배포, 구성요소 정보를 표시한다.
- 접힌 카드에는 화살표, 프로젝트 이름, 상태 배지, 최근 배포 시각만 표시한다.
  상태 점은 이름 영역의 일부로 계속 표시한다.
- 저장된 값이 없는 프로젝트는 기본적으로 펼쳐진다.
- 각 프로젝트의 상태는 독립적이다. 한 카드를 접어도 다른 카드에는 영향을
  주지 않는다.

## 구조

현재 `ProjectSheet`의 데이터 가공과 상세 마크업은 서버 컴포넌트에 남긴다.
새로운 작은 클라이언트 컴포넌트가 다음만 담당한다.

1. 프로젝트별 접힘 상태 관리
2. 화살표 버튼 렌더링
3. 상세 영역 표시/숨김
4. 브라우저 저장소 읽기와 쓰기

서버 컴포넌트는 헤더 내용과 상세 내용을 React 노드로 만들어 클라이언트
래퍼에 전달한다. 따라서 `componentObservations`의 `Map` 같은 서버 전용 데이터
구조를 클라이언트 경계로 직렬화하지 않는다.

## 상태와 저장

- 저장 키는 버전과 프로젝트 ID를 포함한
  `deployhub:project-card-collapsed:v1:{projectId}` 형식을 사용한다.
- 값 `1`은 접힘을 의미한다. 키가 없거나 다른 값이면 펼침으로 취급한다.
- 서버 렌더링과 최초 hydration은 펼친 상태로 일치시킨다. 마운트 후 저장값을
  읽어 필요한 카드만 접는다.
- `localStorage` 접근이 차단되거나 예외가 발생하면 오류를 사용자에게 노출하지
  않고 현재 탭의 메모리 상태로 계속 동작한다.
- 프로젝트 삭제에 따른 과거 키 정리는 이번 범위에서 하지 않는다. 키 크기가
  작고 프로젝트 ID별로 분리되므로 기능 동작에는 영향이 없다.

## 접근성

- 화살표는 이름 링크와 분리된 실제 `button` 요소다.
- 버튼은 현재 상태에 맞는 `aria-expanded` 값을 가진다.
- 버튼의 `aria-controls`는 같은 카드의 상세 영역 ID를 가리킨다.
- 접근 가능한 이름은 프로젝트 이름을 포함해 `프로젝트명 접기` 또는
  `프로젝트명 펼치기` 형식으로 제공한다.
- 상세 영역은 접힌 동안 `hidden` 처리해 키보드와 스크린 리더 탐색에서도
  제외한다.

## 시각 동작

- 화살표는 펼침/접힘 상태가 즉시 구분되도록 방향을 바꾼다.
- 기존 카드의 여백, 테두리, 상태 색상, 이름 링크 스타일은 유지한다.
- 접힌 카드에는 상세 영역의 위쪽 구분선과 여백이 나타나지 않는다.
- 모바일과 데스크톱에서 같은 단일 카드 마크업을 사용한다.

## 테스트

- 기본 상태에서 카드 상세가 펼쳐져 있는지 검증한다.
- 버튼 클릭 시 상세 영역이 숨겨지고 `aria-expanded`가 갱신되는지 검증한다.
- 같은 프로젝트의 저장된 접힘 상태가 마운트 후 복원되는지 검증한다.
- 프로젝트별 저장 키가 독립적인지 검증한다.
- `localStorage` 읽기 또는 쓰기 실패 시에도 버튼이 동작하는지 검증한다.
- 접힌 헤더에 이름, 상태 배지, 최근 배포 시각이 남고 저장소·구성요소 상세는
  숨겨지는지 검증한다.
- 프로젝트 이름 링크가 기존 상세 URL을 유지하는지 검증한다.

## 범위 제외

- 모든 카드를 한 번에 접거나 펼치는 전역 버튼
- 사용자 계정이나 서버 DB에 접힘 상태 동기화
- 프로젝트 이름 클릭으로 접기/펼치기
- 카드 애니메이션
- 과거 `localStorage` 키 정리
