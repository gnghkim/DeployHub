# FE 대비 및 프로젝트 카드 상호작용 보정 설계

## 배경

프로젝트 카드의 시각적 위계를 강화하기 위해 전역 색상 토큰, 카드 타이포그래피,
호버 스타일이 수정되었다. 새 배경과 본문 색상은 선명해졌지만 `--annotation`과
`--absent`가 작은 텍스트에 쓰이기에는 대비가 부족하고, 공용 `Sheet`의 호버 효과가
프로젝트 카드 외의 비대화형 구성도와 발견 화면까지 확장된다. 프로젝트명 링크도
기존 밑줄 피드백이 사라져 링크임을 알아보기 어려워졌다.

## 목표

- 사용자가 선택한 어두운 배경과 강화된 프로젝트 카드 타이포그래피를 유지한다.
- `--annotation`과 `--absent`를 14px 이하 일반 텍스트에도 쓸 수 있도록
  `--paper` 및 프로젝트 카드 호버 배경에서 WCAG AA 4.5:1 이상의 대비로 조정한다.
- 프로젝트 카드에만 호버 및 키보드 포커스 강조를 적용한다.
- 프로젝트명 링크가 마우스와 키보드 모두에서 명확한 상호작용 피드백을 제공하게 한다.
- 데이터 조회, 접기 상태, 라우팅, 카드 내용은 변경하지 않는다.

## 선택한 시각안

비교 화면의 A안인 **균형 보정 · 프로젝트 카드만**을 적용한다.

- `--annotation`: `#8b949e`
  - `--paper: #111316` 대비 약 6.05:1
- `--absent`: `#7e8893`
  - `--paper: #111316` 대비 약 5.17:1
  - `--grid: #1d2024` 대비 약 4.54:1
- `--canvas`, `--paper`, `--grid`, `--rule`, `--line`, `--line-mute`와 상태 색상은
  현재 사용자 변경값을 유지한다.
- 프로젝트명 `text-base font-semibold`, 상세 영역 `text-sm`, 배포 시각 `text-[13px]`
  변경도 유지한다.

두 보조색은 모두 AA 기준을 만족하면서 `line-mute`보다 낮은 위계를 유지한다.
구조 연결 문자는 `aria-hidden` 상태로 낮은 불투명도를 계속 사용할 수 있지만,
의미 있는 배포 시각과 보조 설명은 불투명 토큰 자체로 충분한 대비를 갖는다.

## 컴포넌트 경계

### 공용 `Sheet`

`Sheet`는 프로젝트 카드뿐 아니라 발견 화면과 프로젝트 상세 구성도에도 사용된다.
따라서 공용 컴포넌트에서는 새 호버 배경, 호버 테두리, 전환 및 inset 그림자를
제거하고 기존의 정적인 표면 역할만 유지한다.

### `ProjectSheet`

프로젝트 카드가 `Sheet`에 전달하는 `className`에만 다음 스타일을 둔다.

- 색상 전환
- 기존 토큰을 이용한 호버 테두리
- 기존 UI 관례인 낮은 흰색 투명도의 호버 배경
- 호버와 동일한 `focus-within` 피드백
- 사용자 변경에서 추가된 미세한 inset 그림자

호버 색상에는 새 고정 hex 값을 추가하지 않는다. 이렇게 하면 프로젝트 카드만
강조되고 공용 `Sheet` 소비자는 클릭 가능한 카드처럼 보이지 않는다.

## 링크 상호작용

프로젝트명 링크의 기본 타이포그래피는 유지한다. 마우스 호버에는 밑줄을 복원하고,
키보드 포커스에는 밑줄과 명확한 outline을 제공한다. `#f8f9fa`에서 흰색으로 바뀌는
미세한 색상 변화만으로 링크 상태를 전달하지 않는다.

접기 버튼의 기존 `aria-expanded`, `aria-controls`, focus outline과 로컬 저장소 동작은
변경하지 않는다. 카드 전체를 링크로 만들지 않아 접기 버튼 및 내부 URL과의 중첩
상호작용도 만들지 않는다.

## 테스트와 검증

- 디자인 토큰 테스트에서 hex 색상을 읽어 상대 휘도와 대비를 계산한다.
- `--annotation`과 `--absent`가 `--paper`, `--grid` 및 프로젝트 카드 호버 배경에서
  각각 4.5:1 이상인지 검증한다.
- 렌더 테스트에서 프로젝트명 링크의 hover underline과 focus-visible 피드백을 검증한다.
- 소스 계약 테스트에서 공용 `Sheet`에는 호버 스타일이 없고 `ProjectSheet`에만
  프로젝트 카드 강조 스타일이 있는지 검증한다.
- 관련 렌더 테스트, 웹 타입 검사, 프로덕션 웹 빌드를 실행한다.

## 범위 밖

- 밝은 테마 추가
- 카드 전체 클릭 영역화
- 프로젝트 카드 레이아웃이나 접기 상태 저장 방식 변경
- 다른 화면의 타이포그래피 및 간격 재설계
- 상태 색상(`fault`, `caution`, `confirm`, `accent`) 변경
